Scientific design rationale is kept in [decisions/](decisions/). Decisions describe why an implementation exists; current code/configuration defines its behavior. Dated inspection reports, research logs, and old implementation plans remain local and are not the public operating manual.

Keep API contracts next to the function, parameter descriptions next to the configuration, and decision history here. Avoid duplicating the same operational instructions in agent notes, the README, and stage guides.
